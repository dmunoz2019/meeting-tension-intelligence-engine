# Changelog

## 0.2.0 - 2026-07-03

- Added evidence-first domain contracts and stable provenance identifiers.
- Added ports for ASR, diarization, alignment, embeddings, reranking, PII, and telemetry.
- Added lazy adapters for faster-whisper, pyannote.audio, and Presidio.
- Added BM25 + dense retrieval, Reciprocal Rank Fusion, and optional reranking.
- Added calibration, retrieval, classification, and evidence-span evaluation metrics.
- Added an approved upstream registry with pinned refs, SPDX licenses, and private weight policy.
- Added multi-version CI, packaging smoke tests, and 11 new tests.
